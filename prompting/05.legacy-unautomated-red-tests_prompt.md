### Turn 1 - AI Answer

문서와 관련 테스트/레거시 코드를 확인한 뒤, 미자동화 항목은 `RED-01/02`, `RED-03`, `RED-06~10`, `RED-11/12`, `RED-13`이라고 정리했다.

주요 제안:

- CSV 테스트를 우선 자동화하고, `parseCsvLine()`을 테스트 가능한 경계로 분리하는 방향을 제안했다.
- 다운로드 상태 테스트는 `fil_data` 전역 상태를 `DownloadState` 또는 `FilteredResultStore`로 분리하는 방향을 제안했다.
- 입력 검증 테스트는 `/analyze`, `/upload` HTML 결과보다 서비스 결과 타입을 검증하는 방식이 좋다고 제안했다.
- 세션/사용자 경계는 `SessionStore` 인터페이스와 `sessionId`별 저장소 테스트가 필요하다고 제안했다.
- 서버 시작 실패는 `ServerRunner::start(host, port)`처럼 성공/실패 결과를 반환하는 경계를 만들고 테스트하는 방향을 제안했다.

- `main`을 `feedback_analyzer_legacy_main`으로 치환해 `main.cpp`를 테스트 번역 단위에 포함하고, 기존 라우트 람다를 직접 호출했다.
