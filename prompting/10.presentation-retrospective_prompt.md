# 프롬프트 기록: Presentation Retrospective

## Export 원칙

- 이 파일은 사용자 Prompt와 AI 답변의 Export 기록이다.
- 원문 보존을 우선한다.
- 숨겨진 시스템 메시지와 비공개 내부 추론은 제외한다.

## 대화 전문

### Turn 1 - User Prompt

```text
넌 프리젠테이션 전문가야.
이번 실습 프로젝트에서 Before/After 코드 비교와 AI활용 경험에 대해 5분 내외로 발표할 수 있도록 MarkDown 으로 정리해줘.
```

### Turn 1 - AI Answer

```text
요청하신 5분 발표용 Markdown을 프로젝트 맥락에 맞춰 구성하겠습니다. 먼저 요구사항과 리팩토링 문서에서 Before/After와 AI 활용 포인트를 확인해 발표 흐름을 잡겠습니다.

문서 기준으로 보면 발표의 핵심 축은 “레거시 결함을 RED 테스트로 드러내고, Golden Master로 기능을 고정한 뒤 구조를 개선했다”입니다. 실제 코드의 Before/After 비교에 쓸 만한 지점을 몇 군데 더 확인하겠습니다.
```

AI는 `docs/requirement.md`, `docs/Refactoring 작업 지시서.md`, `docs/RED_단계_개선_작업지시서.md`, `src/cpp/main.cpp`, `src/cpp/RequestHandlers.h`, `src/cpp/FeedbackClassifier.h`, `src/cpp/CsvFeedbackImporter.h`, `src/cpp/FilteredResultStore.h` 등 관련 파일을 확인한 뒤 5분 발표용 Markdown 초안을 작성했다.

주요 답변 요약:

- 프로젝트 소개
- Before: 라우트의 과도한 책임, stale download, 세션 상태 섞임, 분석/필터 기준 불일치, CSV 처리 문제, 로그 개인정보 위험
- After: `main.cpp`, `RequestHandlers`, `FilteredResultStore`, `FeedbackClassifier`, CSV import/export 책임 분리
- Golden Master와 RED Case 테스트 전략
- AI 활용 경험
- 배운 점

### Turn 2 - User Prompt

```text
docs에 발표자료.,d 파일로 저장해줘
```

### Turn 2 - AI Answer

```text
현재 Ask mode라서 파일 생성이나 수정은 할 수 없습니다.

아래처럼 `docs/발표자료.md` 파일로 저장하면 됩니다. Agent mode로 전환해 주시면 제가 직접 생성해드릴 수 있어요.
```

Ask mode 제한으로 인해 파일 저장은 수행하지 않고, Markdown 본문을 응답으로 제공했다.

### Turn 3 - User Prompt

```text

```

### Turn 3 - AI Answer

```text
Agent mode로 전환되었으니 요청하신 발표 자료를 `docs/회고.md`로 저장하겠습니다. 먼저 같은 파일이 이미 있는지 확인한 뒤 새 파일로 추가하겠습니다.

`docs/회고.md`는 아직 없어서 새 Markdown 파일로 생성하겠습니다. 발표 시간이 5분 내외가 되도록 섹션과 문장을 발표용 톤으로 정리해 저장합니다.

파일 생성이 완료되었습니다. 저장 내용이 정상적으로 들어갔는지 간단히 확인하고, 편집 파일 기준 진단도 확인하겠습니다.
```

최종 답변:

```text
저장했습니다: `docs/회고.md`

내용 확인도 완료했고, 해당 Markdown 파일에 대한 linter 오류는 없습니다.
```

### Turn 4 - AI Answer

```text

기존 파일명 충돌은 없습니다. Markdown 내용을 발표용 HTML 문서로 옮기되, 브라우저에서 바로 열어 보기 좋도록 간단한 스타일과 섹션 카드를 포함해 만들겠습니다.

HTML 파일을 생성했습니다. 이제 파일이 정상적으로 저장됐는지 앞부분을 확인하고 진단 결과를 확인하겠습니다.
```

최종 답변:

```text

브라우저에서 바로 열 수 있는 단일 HTML 파일이고, `docs/회고.md` 내용을 바탕으로 발표용 카드형 레이아웃과 간단한 Before/After 비교 영역을 넣었습니다. Linter 오류도 없습니다.
```
