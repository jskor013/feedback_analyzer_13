Feedback Analyzer Refactoring 결과 보고서

C++17 / CMake / Catch2 호환 환경 기준, R1~R8 리팩토링 완료 후 클래스 구조 비교

1. 요약

이번 리팩토링은 기능 변경 없이 기존 Golden Master와 RED 회귀 동작을 유지하면서 main.cpp 중심의 다중 책임 구조를 요청 처리, 상태 저장, 분류 규칙, CSV, 렌더링, 로깅 경계로 분리했다.

최종 검증 cmake build 성공, CTest 3개 테스트 그룹 100% PASS

단계 커밋 주요 리팩토링 구조 개선 효과

4. 의존성 방향

영역 변경 후 방향
Boundary httplib route, ConsoleLogSink, FeedbackPageRenderer, CSV import/export
Control RequestHandlers가 요청 흐름과 상태 변경을 조정
Entity/Domain Feedback, Constants, FeedbackClassifier, TextAnalyzer, Filters
테스트 코드 변경 금지 조건 때문에 일부 레거시 wrapper와 fil_data 호환 alias는 유지했다. 후속으로 테스트가 새 API를 사용하도록 전환되면 wrapper 제거를 검토할 수 있다.
