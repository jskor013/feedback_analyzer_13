## 개요

- 작업 일시: 2026-05-22 10:04 ~ 10:21 KST

## 변경 내용

- 수정/추가한 파일:
  - `tests/red_cases/legacy_unautomated_red_cases_test.cpp`

- 주요 구현 내용:
  - 테스트 전용 fake `httplib` 경계를 추가해 실제 포트 바인딩 없이 `main.cpp`의 기존 라우트 람다를 호출했다.
  - `src` 폴더의 레거시 구현과 `CMakeLists.txt`는 수정하지 않았다.
  - 다운로드 상태, 사용자 상태 경계, CSV 입력/출력, 입력 검증, 서버 시작 실패 케이스를 자동화했다.
- 테스트 변경 내용:
  - `RED-01`: 빈 필터 결과 이후 이전 다운로드 데이터가 재사용되는지 검증.
  - `RED-02`: 필터 전 다운로드가 명확히 차단되는지 검증.
  - `RED-03`: 서로 다른 사용자/세션 요청이 전역 피드백 상태를 공유하는지 검증.
  - `RED-06 ~ RED-10`: CSV 헤더, 텍스트 컬럼 위치, 쉼표, 따옴표, 줄바꿈 처리를 검증.
  - `RED-11 ~ RED-12`: 공백 입력과 파일 미선택 업로드의 명확한 오류 메시지를 검증.
  - `RED-13`: 서버 시작 실패가 실패 종료 코드로 전달되는지 검증.

## 주의 사항

- 남은 리스크:
  - RED 테스트는 현재 레거시 결함을 고정하기 위한 실패 테스트이므로, 리팩토링 전까지 테스트 실행은 종료 코드 1을 반환한다.
  - 테스트 파일에서 `main.cpp`를 같은 번역 단위에 포함하는 방식은 `src` 수정 금지 조건을 만족하기 위한 테스트 전용 접근이다.
- 후속 작업:
  - 다운로드 상태, CSV 처리, 세션 경계, 입력 검증, 서버 시작 결과 처리를 `src`에서 테스트 가능한 단위로 분리한 뒤 RED 테스트를 Green으로 전환한다.
